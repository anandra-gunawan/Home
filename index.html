ℹ️ Tentang Portal

Portal ini menampilkan daftar aplikasi web dalam satu halaman. Klik kartu untuk membuka aplikasi di tab baru.

Menambah / mengubah aplikasi: buka file index.html di editor, lalu edit array DAFTAR_APLIKASI di bagian paling atas blok <script>. Setiap aplikasi adalah satu objek: 

{
  nama:     "Nama Aplikasi",
  url:      "https://contoh.com",
  deskripsi:"Keterangan singkat",
  ikon:     "🛒",           // emoji atau URL gambar
  kategori: "Keuangan"
}

Urutan kartu otomatis mengikuti abjad nama aplikasi.

Install di Android: buka halaman lewat Chrome → menu ⋮ → Install app (tombol "⬇️ Install" di atas juga muncul otomatis bila memenuhi syarat).
